# VixWin Platinum 3.6.3: инициализация HKCU через GPO

[Техническая статья](https://notes.shandrov.ru/ru/notes/windows/gpo-vixwin-platinum-user-profile-deployment/) · [English README](README.md)

Обезличенная **демонстрационная адаптация** проверенной схемы внедрения, не буквальная копия производственных сценариев. Предварительная подготовка восьми значений HKCU, четыре UI-шаблона, проверка сетевой базы, резервное копирование, журнал и пропуск уже настроенного пользователя.

**НЕ ЗАПУСКАТЬ БЕЗ ДОРАБОТКИ.** В скриптах — `ad.example.com`, `CORP`, `PC-01`, `PC-02`, `nas01`, тестовый IP `192.0.2.31` и заведомо неверные SHA256. Реальные .reg-файлы намеренно не включены. Скрипт прекращает работу, пока шаблоны не будут проверены и хеши не заменены.

Не устанавливает VixWin, не создаёт базу пациентов и не изменяет медицинские изображения. Важно запускать в контексте самого пользователя, а не SYSTEM. `DatabaseReadOnly=1` относится к конкретному обследованному случаю, не универсален.

См. `docs/gpo-setup.md` и исходники в `scripts/`. Публичные примеры самостоятельно не проходили полный интеграционный тест. Лицензия пока не выбрана.
